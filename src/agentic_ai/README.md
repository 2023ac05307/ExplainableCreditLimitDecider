# Agentic AI Layer

This module implements the **Agentic Decision Layer** on top of
model-based inference.

## Role in the System

The Agentic AI layer:
- Does **not** train models
- Does **not** run neural networks
- Operates purely on model outputs and policy constraints

It is responsible for:
- Enforcing business and regulatory rules
- Making final credit limit decisions
- Generating human-readable rationales
